# Experiment briefs

One file per experiment, written by the planning session. A brief starts as `draft`. It becomes `approved` only after the PI explicitly approves it, and the date is recorded in the brief. The compute node runs only briefs whose status is `approved`. Start from `TEMPLATE.md`.
